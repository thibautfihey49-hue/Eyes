# 👁️ EYES — Caméra P2P

Application web **PWA** de visionnage caméra en temps réel en **P2P direct**.

> 🔒 Aucun serveur intermédiaire — la vidéo passe directement entre les appareils.
> 📷 La caméra ne s'allume **que du côté cible** — jamais du côté visionneur.

---

## ✨ Fonctionnalités

- 📱 **PWA installable** — comme une vraie application
- 🌐 **P2P WebRTC** — connexion directe, pas de serveur vidéo
- 📷 **Caméra seulement du côté cible** — confidentialité garantie
- 📶 **Fonctionne hors ligne** — fichiers mis en cache
- 💻 **Multi-plateforme** — Android, iOS, Windows, Mac

---

## 🚀 Utilisation

### 📱 Côté Caméra (émetteur)
1. Ouvre **`index.html`** dans le navigateur
2. Autorise l'accès à la caméra
3. Note ton **ID** (ex: `ABCD-1234`)
4. Laisse la page ouverte ✅

### 📱 Côté Visionneur (récepteur)
1. Ouvre **`index.html`**
2. Saisis l'ID de la caméra
3. Clique **▶️ VOIR EN DIRECT**
4. ✅ La vidéo apparaît en direct !

---

## 📲 Installation comme application

1. Ouvre l'URL dans Chrome/Firefox
2. Clique sur **"Installer"** dans la barre du navigateur
3. 🎉 Icône sur l'écran d'accueil — plein écran, sans navigateur
